# Calculator Web App

A sleek and interactive calculator built using **HTML, CSS, and JavaScript**. This project replicates the functionality of a basic calculator with a modern UI and responsive layout.

---

## Overview

This calculator allows users to perform standard arithmetic operations such as addition, subtraction, multiplication, and division. It is designed with a clean interface and smooth user interaction.

---

## Features

-  Basic arithmetic operations (+, −, ×, ÷)  
-  Real-time input display  
-  Clear (AC) functionality  
-  Positive/Negative toggle (+/-)  
-  Percentage (%) calculation  
-  Responsive button layout  
-  Fast and lightweight  

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling and layout  
- **JavaScript** – Logic and interactivity  
---

## ▶️ How to Run

1. Download or clone the repository  
2. Open the project folder  
3. Open `index.html` in your browser  

---

##  Core Functionality

- Button clicks are captured using JavaScript  
- Values are dynamically updated in the display  
- Expressions are evaluated using JavaScript logic  
- Special operations like AC, %, and +/- are handled separately
